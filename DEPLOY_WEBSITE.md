# Put your CAT + IREN analyzer online

This is a ready-to-deploy Streamlit website. To get a public URL:

1. Create a free GitHub account if you don't have one.
2. Create a new repository (for example `cat-iren-analyzer`).
3. Upload the contents of this ZIP (not the ZIP itself) to the repository.
4. Visit https://share.streamlit.io and sign in with GitHub.
5. Choose **Create app** → **Deploy a public app from GitHub**.
6. Select your repository, branch `main`, and main file path `app.py`.
7. Click **Deploy**. Streamlit will provide a website URL you can bookmark and open from any device.

Note: Deployment requires your GitHub and Streamlit accounts. The assistant cannot publish the website without access to hosting accounts.

Data: Yahoo Finance via yfinance; availability and delays vary. Scenarios are hypothetical, not forecasts.
